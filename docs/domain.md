# 林地价值证据仓领域约定

项目面向城口县集体林权改革与林下产业协作场景，由县金融服务中心建设，
统一评估机构、银行与林农对同一片林地的价值依据。业务记录必须区分来源、
发生时间（含采集季节）与当前有效版本；所有对外结论都必须能够追溯到所
采用的证据集合、市场参数版本与计算公式版本。

## 核心对象

* **证据（Evidence）**：现场调查（field_survey）、经营方案
  （management_plan）、收益记录（income_record）、第三方估值
  （third_party_valuation）四类。证据登记后不可变，按"类别 + 来源文号
  + 规范化内容"生成业务指纹；同一材料重复上传或离线补传只保留一条。
* **市场参数（MarketParameters）**：木材价格、中药材亩均收益、康养
  年收益、道路可达性系数、管护成本、折现率。参数连续修订只追加新版本，
  旧值随旧版本永久保留。
* **估值版本（ValuationVersion）**：按"估值目的"组织（如银行融资
  抵押估值）。创建版本即冻结输入快照（证据指纹有序集合 + 参数快照 +
  公式版本 forest-income-v1 + 评估资格），并计算快照哈希供复算比对。
* **复核记录（ReviewRecord）**：争议值进入双人复核，两名相互独立且
  均非编制人的复核人共同通过方可放行；任一否决即驳回，只能形成新版本。

## 版本状态机

```
frozen → calculating → calculated → published
                         ↘ in_review（争议）→ calculated / review_rejected
```

计算中断时版本停留 calculating，无部分价值落库，可安全重试。

## 发布闸门（全部通过才生成唯一正式结论）

1. 价值已计算成功；
2. 发布当日评估资格仍在有效期内（过期直接阻止，错误码
   `qualification_expired`）；
3. 争议值已取得两名独立复核人批准（`review_required` /
   `review_rejected`）；
4. 同一估值目的至多一份 PUBLISHED 结论，结论编号全局唯一；
5. 仅 publisher 角色可发布，appraiser 编制、reviewer 复核、publisher
   发布三权分立。

## 可追溯口径

每版结论返回：版本序号、取代关系（supersedes）、证据 ID 与指纹列表、
快照哈希、市场参数快照、公式版本、价值明细（林木 / 中药材现值 / 康养
设施现值 / 管护义务现值扣减）、物理量输入、采集季节、第三方参照值与
争议标记、资格与发布信息。融资复核时可据此逐项解释季节差异与参数修订
差异，而不是只看到"最后一个数字"。

涉及个人、机构或敏感地点的信息只向职责范围内的角色开放。
