# 林地价值证据仓领域约定

项目面向集体林权改革与林下产业协作场景，业务记录需要区分来源、发生时间与当前有效版本。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放，所有对外结果都应能够追溯到采用的数据版本。

## 核心概念

- **林地（Parcel）**：评估对象，一宗林地可含多种经营成分（如中药材、康养设施）。
- **评估师（Appraiser）**：持有评估资格，资格含到期日；发布当日资格过期即阻断发布。
- **证据（Evidence）**：四类来源——现场调查、经营方案（含管护义务）、收益记录、第三方估值（仅作交叉核对）。按 `material_key` 标识同一份材料；补测只追加版本号，内容指纹（SHA-256）用于识别完全重复的上传。`recorded_on` 可早于 `submitted_at`，支持离线补传。
- **市场参数（MarketParams）**：价格指数、资本化率、折现率等，每次修订追加新版本。
- **估值版本（Valuation）**：每次创建按（林地、估值目的、幂等键）收敛为唯一版本，版本号连续；状态流转为 `frozen → ready（可经 in_review）→ published`，计算失败为 `interrupted`，复核未通过为 `rejected`。
- **快照（Snapshot）**：创建估值时按估值目的与季节冻结的输入副本（各材料适用季节最新版本 + 最新参数版本），生成指纹。证据与参数事后追加版本不影响已冻结快照。
- **结论（Conclusion）**：正式发布的估值结果。每宗林地每个目的至多一份 `official` 结论；新版本发布后旧结论标记为 `superseded` 并记录替代链。

## 不变量

1. **只追加**：证据补测、参数修订均产生新版本，历史版本、快照与结论永不改写。
2. **快照冻结**：每版价值只依据其快照计算，相同快照必产生相同价值；林下作物、道路可达性、管护义务的季节差异通过季节选取证据版本体现。
3. **幂等**：所有写入携带 `idempotency_key`；重复上传、离线补传重放、计算中断重试都收敛为同一资源，同一批输入不会产生两份正式结论。
4. **发布准入**：资格过期阻止发布；争议值须两名不同复核人双人通过才可发布，任一拒绝即终止。
5. **可追溯**：`/valuations/{id}/trace` 串联价值、计算口径分解（breakdown）、快照、引用证据版本、参数版本、复核记录与结论。

## 估值口径

年净收益（按成分价格指数调整）÷ 资本化率 × 道路可达性系数 − 管护义务年金现值。
第三方估值不并入计算值，仅在分解中保留供核对。
